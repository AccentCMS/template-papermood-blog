Every blog has a first post. This is it -- and it is also the translated
one: `default.de.md` and `default.fr.md` sit next to this file, so the
language switcher in the header offers DE and FR on exactly this post.
The interface -- dates, reading time, navigation -- follows the language
of the page.

Delete this post when you write your own first one.
